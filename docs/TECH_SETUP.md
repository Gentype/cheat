# ТЕХНИЧЕСКОЕ УСТРОЙСТВО MYDRIASIS

Движок: **Godot 4.3 stable**, рендер **Forward+**.
В проекте нет ни одной текстуры и ни одного звукового файла: всё, что видно и
слышно, генерируется кодом.

---

## 1. Запуск

```
Godot 4.3 → Project Manager → Import → project.godot → F5
```

Первый запуск: дать редактору один раз импортировать ресурсы (`art/`, `icon.svg`).

Главная сцена — `res://scenes/ui/splash.tscn` (заставка студии), из неё переход
в меню, из меню — в бит `res://scenes/game/ward_night.tscn`.

---

## 2. Структура

```
project.godot            точка входа и порядок автолоадов
shaders/                 9 шейдеров: тело-дыра, руки, маска, кафель, стекло,
                         ткань, монитор, грейд, вуаль
scripts/autoload/        InputActions, GameState, Quality, AudioDirector,
                         SaveSystem, SceneRouter
scripts/core/            SynthVoice (синтез звука), ShaderLibrary (реестр
                         шейдеров), MeshBuilder (процедурная геометрия)
scripts/camera/          CameraFrame (данные ракурса), CameraDirector (режиссёр),
                         CameraTrigger (зоны навязывания)
scripts/player/          PlayerController, Avatar, ArmRig, AvatarBuilder
scripts/world/           LevelBase, ward_level (бит), Props (реквизит),
                         MaterialFactory, EnvironmentRig, Interactable
scripts/vfx/             ScreenEffects (post_grade + veil)
scripts/ui/              UITheme, splash, main_menu, pause_menu, settings_menu, HUD
resources/camera_frames/ ракурсы камеры (JSON — данные, а не код)
scenes/                  тонкие обёртки: Control/Node3D + скрипт
art/                     ТОЛЬКО меню, пауза, настройки, знак студии, шрифты
docs/                    GDD, ART_BIBLE, CAMERA_LANGUAGE, TECH_SETUP, ROADMAP
tools/check_gdscript.py  локальная и CI-проверка скриптов
```

**Почему уровни собираются кодом, а не в редакторе.** Блокинг читается в diff'ах,
рецензируется как код и не может «потеряться» при конфликте сцен. `scenes/*.tscn`
сознательно почти пустые: узел + скрипт.

---

## 3. Автолоады (порядок важен)

| Автолоад | Задача | Особенность |
|---|---|---|
| `InputActions` | регистрирует карту ввода кодом | до первой сцены |
| `GameState` | виталитеты, ужас, флаги бита | `PROCESS_MODE_PAUSABLE` |
| `Quality` | уровни качества, сторож FPS, комфорт | `ALWAYS` |
| `AudioDirector` | синтез и проигрывание звука, шины | `ALWAYS` |
| `SaveSystem` | настройки и сохранение обхода | `ALWAYS`, применяет настройки к Quality/Audio |
| `SceneRouter` | переходы со шторкой | `ALWAYS` |

Карта ввода описана кодом (`scripts/autoload/input_actions.gd`), а не в
`project.godot`: так она версионируется вместе с геймплеем и не расходится со
скриптами.

### Управление

`WASD` движение · мышь — голова героя · `E` взаимодействие · `Shift` задержать
дыхание · `Esc` пауза · `F1` отладочная камера · `F2` следующий ракурс ·
`F10` качество.

## 4. Уровни качества

| Уровень | Выборок в диске рассеяния | Масштаб | MSAA | SSAO/SSIL | SDFGI | Объёмный туман |
|---|---|---|---|---|---|---|
| НИЗКОЕ | 8 | 75% | — | — | — | — |
| СРЕДНЕЕ | 16 | 90% | ×2 | SSAO | — | — |
| ВЫСОКОЕ | 24 | 100% | ×4 | SSAO+SSIL | — | да |
| **ВЫСШЕЕ** (по умолчанию) | 32 | 100% | ×4 | SSAO+SSIL | да | да |

* «ВЫСШЕЕ» стоит по умолчанию: проект рассчитан на работу на полную.
* Сторож производительности (`Quality.auto_guard`) плавно опускает **масштаб
  рендера** и никогда не выключает эффекты, несущие смысл.
* Уровни качества меняют и параметры шейдеров: `ShaderLibrary.refresh_all()`
  переоценивает все живые материалы (число выборок, плотность процедурных деталей).

## 5. Шейдеры

| Файл | Тип | Что делает |
|---|---|---|
| `body_hole.gdshader` | spatial, transparent | тело как вырез в кадре: диск рассеяния, хроматика, абсорбция, пульс, давление |
| `hands_reveal.gdshader` | spatial, opaque | руки: поры, вены, грязь, пот, латекс, тремор, холод, контурный свет |
| `mask_visor.gdshader` | spatial, transparent, priority 1 | визор: преломление кадра, конденсат, капли, царапины, туман дыхания |
| `wet_tile.gdshader` | spatial | кафель/краска/бетон: плитка со сдвигом, швы с грязью, вода, потёки, пудлы |
| `glass_dirt.gdshader` | spatial, transparent | стекло: преломление, разводы, отпечатки, мороз, сколы |
| `fabric_gauze.gdshader` | spatial | ткань: плетение, складки, пятна, промокание, ворс |
| `monitor_crt.gdshader` | spatial, unshaded | кардиограмма целиком: сетка, развёртка, фосфор, помехи, асистолия |
| `post_grade.gdshader` | canvas_item | финальный грейд: экспозиция, зрачок, давление, гало, зерно, хроматика |
| `veil.gdshader` | canvas_item | распад восприятия: двоение, туннель, помехи, волны, обесцвечивание |

Материалы создаются кодом через `ShaderLibrary.material(id, params)`.
`ShaderLibrary.set_uniform()` молча пропускает несуществующий юниформ — правка
шейдера на ходу не валит игру.

## 6. Процедурная геометрия

`MeshBuilder` — треугольники с автоматической ориентацией граней.

> **Соглашение Godot:** лицевыми считаются треугольники, идущие по часовой
> стрелке со стороны наблюдателя. Значит, у корректного треугольника векторное
> произведение `(b−a)×(c−a)` направлено **внутрь** поверхности. `MeshBuilder._tri`
> проверяет это по внешней нормали и переворачивает вершины при необходимости;
> флаг `flip_winding` — аварийный переключатель на случай смены соглашения в движке.

Примитивы: `quad`, `rect` (метровые UV), `box`, `ellipsoid`, `cylinder`,
`capsule`, `torus`, `tube_along`, `extrude` (профиль + толщина), `disc`,
`mask_profile`. Есть `to_obj()` для выгрузки в Blender и `bounds()`.

Аватар: телесная оболочка (дыра) + скелет руки (плечо → локоть → кисть →
5 пальцев × 3 фаланги) + маска (профиль лица, обод, клапан, ремни, фильтр) +
фонарь + манжета.

## 7. Процедурный звук

`SynthVoice` — генератор одного звука (шум, синус, металл, влажный хруст,
щелчки, огибающие, фильтры, насыщение, нормализация, петли). `AudioDirector`
содержит рецепты и собирает банк лениво, по первому запросу.

Пять шин: `Master` (компрессор + лимитер + стерео/моно), `Bed` (палата,
реверберация), `Body` (пульс, дыхание, низкие частоты), `SFX` (блок, металл),
`Voices`.

Зацикленные слои склеиваются по фазе: тональные составляющие уложены в целое
число периодов на длину петли (`_loop_freq`), начало срезано на время
прогрева фильтров (`trim_head`), поэтому петля не щёлкает.

Сердце звучит по факту удара из `GameState.beat`: темп, громкость и питч идут
от виталитетов, а не от таймера звука.

## 8. Шрифты

`art/fonts/DejaVuSansMono.ttf`, `-Bold`, `DejaVuSansCondensed-Bold.ttf`
(лицензия — `art/fonts/LICENSE_DEJAVU.txt`). Кириллица проверена: 180–256
глифов в диапазоне U+0400–U+04FF, есть Ё/ё. Если папку удалить, `UITheme`
молча упадёт на шрифт движка — интерфейс останется читаемым.

## 10. Проверка и сборка

Локально (без движка):

```
pip install gdtoolkit
python3 tools/check_gdscript.py           # только парсинг
python3 tools/check_gdscript.py --lint    # плюс правила стиля (.gdlintrc)
```

С движком (полная проверка, включая компиляцию шейдеров):

```
python3 tools/check_gdscript.py --godot /path/to/Godot_v4.3-stable_linux.x86_64 --lint
```

CI (`.github/workflows/ci.yml`) делает именно это: ставит gdtoolkit, скачивает
Godot 4.3, импортирует проект и падает при любой ошибке скрипта или шейдера.

Экспорт: `godot --headless --export-release "Linux/X11"` (или профиль под Windows
в `export_presets.cfg`, файл в репозиторий не кладётся — он локальный).

## 11. Производительность: на что смотреть

* `body_hole` — самый дорогой шейдер: маска рассеяния на весь силуэт. Число
  выборок — первое, что опускается на слабых машинах.
* `mask_visor` и `glass_dirt` читают screen texture: они рисуются поверх 3D и
  должны иметь `render_priority` выше дыры тела (визор = 1).
* Реверберация палаты стоит на шине `Bed`, а не на каждом источнике.
* Пул голосов (24 2D + 20 3D) исключает создание узлов во время игры.
