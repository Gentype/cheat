# Mydriasis

Психологический боди-хоррор о распаде восприятия на грани жизни и смерти.
Внутренний проект студии **Mydriasis** · Godot **4.3** · Forward+.

> Мидриаз — стойкое патологическое расширение зрачка без реакции на свет.
> Двусторонний фиксированный мидриаз — маркер запредельной комы и гибели нервной системы.

## Быстрый старт

1. Установить **Godot 4.3** (stable) — Forward+ рендер.
2. `Project Manager → Import → project.godot`.
3. Дать редактору один раз импортировать ассеты (папка `art/`, `icon.svg`).
4. F5. Главное меню → **НОВАЯ СМЕНА**.

Управление: `WASD` — движение, `Мышь` — взгляд, `E` — взаимодействие,
`Shift` — задержать дыхание, `Esc` — пауза, `F1` — отладка камеры,
`F2` — переключение ракурса, `F10` — профилирование качества.

## Философия проекта (коротко)

* **Персонажа нет.** Тело главного героя — не модель и не фотография. Тело — это
  оптическая дыра: пиксели фона, размытые по диску рассеяния. Видны только руки и маска.
  Никакой генерации «человека» для геймплея — в кадре человек только через оптику.
* **Камера — главный автор.** Фиксированные ракурсы, жёсткие склейки, микро-дрейф,
  дыхание, взгляд-саккады. Референс языка камеры — Buckshot Roulette.
* **Мидриаз как интерфейс.** Расширение зрачка, давление манжеты, плёночное зерно и
  гало — не пост-эффект «для красоты», а прямая шкала состояния героя.

## Структура

```
shaders/     библиотека шейдеров (тело-дыра, маска, руки, мокрый кафель, стекло, грейд)
scripts/     autoload'ы, камера, персонаж, мир, UI, звук
scenes/      тонкие обёртки: узел + скрипт (уровни собираются кодом)
resources/   данные: ракурсы камеры (JSON)
art/         ИЗОБРАЖЕНИЯ ТОЛЬКО ДЛЯ МЕНЮ / ПАУЗЫ / НАСТРОЕК / ЛОГО
docs/        дизайн-документы
tools/       проверка скриптов, выгрузка геометрии в OBJ
```

## Проверка и CI

Проверка скриптов (движок не нужен — только gdtoolkit):

```
pip install gdtoolkit
python3 tools/check_gdscript.py --lint
```

Выгрузка процедурной геометрии в Blender (болванки для правки формы;
материалы остаются процедурными):

```
godot --headless --path . --script tools/export_props.gd
```

GitHub Actions (`.github/workflows/ci.yml`) ставит gdtoolkit, скачивает Godot 4.3,
импортирует проект и падает при любой ошибке скрипта или шейдера.
